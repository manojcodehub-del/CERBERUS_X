# Optional local hologram projector model

The dashboard will load `/models/hologram-projector.glb` when that file is present. Otherwise it renders the lightweight procedural projector in the application.

The referenced Grab3D Hologram Projector listing describes its GLB as CC0 1.0 and includes a license file with the model package: <https://grab3d.com/models/sci-fi/hologram-projector/>.

No GLB is included here. The runtime cannot retrieve the file in this environment, so no third-party model or texture has been added. If you download it later, place only the actual GLB and its included license/manifest files in this directory.
